# LobbyDesk downloads

This repository provides official Windows downloads and automatic updates for LobbyDesk.

[Download the latest release](https://github.com/IWantWORKINGMods/LobbyDeskFortniteLobbyBot/releases/latest)

Choose **LobbyDesk.exe** to run the app, or the ZIP for the app, guide, and license notices. A valid LobbyDesk license is required for activation. Availability and purchasing are managed on the [LobbyDesk website](https://lobbydesk.cloud-ip.cc).

For private support or lost-key help, contact **bradyirizarry179@gmail.com**. Never post license keys, Epic credentials, or diagnostic reports in a public issue.

The application source is maintained separately. This repository contains release files, user information, and distribution notices. The existing MIT license and third-party notices remain included with each application download.
